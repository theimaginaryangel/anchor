# Sample Data

This directory holds synthetic documents for testing and demos. These are fake — no real client data, no real personal information.

## Planned Documents

1. **Fictional Employee Handbook** (~10 pages) — Company policies, PTO rules, code of conduct, benefits overview. The kind of document where someone would ask "how many vacation days do I get?" and expect a specific, cited answer.

2. **Fictional Rental Agreement** (~8 pages) — Lease terms, maintenance responsibilities, payment schedules, early termination clauses. Good for testing questions like "what happens if I break the lease early?" where the answer needs to cite the right clause.

## Why These Documents

The demo needs documents that are:
- **Familiar to anyone** — everyone has dealt with a handbook or a lease
- **Full of specific, findable facts** — dates, numbers, conditions that make good test questions
- **Long enough to need chunking** — a one-page document wouldn't test the retrieval pipeline

These will be added as PDFs in Phase 6.
